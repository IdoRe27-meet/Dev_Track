# My greetings app!

I created a simple greetings flet app. On the surface, it takes a first and last name and displays a greeting message, but if you type the right words - you can do a lot more.

## Easter eggs!

Here are all the inputs you can try in the text fields:

* Type numbers in both fields: The app switches to calculator mode and adds the two numbers together.

* Type "change" in the first field and "color" in the second field: Changes the app background to a random color.

* Type "gen" in the first field and "pass" in the second field: Generates a random 12-character password.

* Type "boom" in the first field: Starts a 5-second countdown on screen and then closes the application.

* Type "reverse" in the first field: Reverses whatever text you typed in the second field.

* Type "rename" in the first field and any text in the second field: Renames the main button to whatever you typed in the second field.

* Type "31" in the first field and "05" in the second field: Turns the background dark blue and displays a birthday greeting.

* Long-press the button: Triggers a rain animation of falling meet logos(!) across the screen.
